# Level-Up Insight 짤 저장소

사내 동호회 잔디봇(Level-Up Insight)이 알림에 띄우는 짤 이미지 호스팅용 리포입니다.

잔디 Incoming Webhook의 `connectInfo[].imageUrl`은 **인증 없이 열리는 http(s) URL만** 렌더링합니다.
사내 공유 드라이브는 조직 정책상 외부 공개가 차단되어 있어 이 리포를 이미지 CDN으로 사용합니다.

사용 URL 형식:
`https://raw.githubusercontent.com/kwag93/levelup-insight-zzal/main/<파일명>`
